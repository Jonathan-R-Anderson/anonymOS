Deploying sets each contract's owner to your connected wallet — you sign every deploy and every write, so you hold ownership. Target network: Ethereum Mainnet (chainId 1). This is MAINNET — gas is real ETH and mintGenesis creates real AXONCoins. Your wallet needs Ethereum Era ETH.

Getting started — kickstart the economy

  1. Connect your wallet (it becomes the owner of every contract you deploy).
  2. Deploy AxonToken first. On-chain it is AXON; the site calls the network token — Anonymous, ticker AXON, written AXONCoins on the site.
  3. Deploy the rest in order (they reference AxonToken/EpochManager/StakeVault by address). Treasury comes after RewardDistributor, because it mints into it.
  4. Hand supply to the Treasury: AxonToken.setTreasury(<Treasury>). Until this is done nothing can mint at all, including epoch rewards.
  5. Seed the allocation: AxonToken.mintGenesis(<Treasury>, amount) mints the supply the Treasury will sell, grant and airdrop from. (amount is in wei — 18 decimals; e.g. 1,000,000 credits = 1000000000000000000000000.)
  6. Wire roles: EpochManager.setDisputeManager(DisputeManager, true), StakeVault.setSlasher(DisputeManager, true), EpochManager.setAggregator(<aggregator>, true). RewardDistributor no longer needs funding by hand — anyone can call Treasury.fundEpoch(epoch) once an epoch settles, and it mints exactly that epoch’s rewards into it.
  7. When bootstrapping is done, call AxonToken.closeGenesis() to permanently lock owner-minting — supply is then governed only by the Treasury, bounded by its per-epoch budget and its immutable cap.

Deploy

Deploy in order (AxonToken first — others reference it). Addresses are saved server-side on success.

Settle an epoch

An epoch whose challenge window has closed with no disputes can be finalized by anyone — no owner, no role. That is deliberate: a settlement only its author can complete is one its author can also withhold. Until somebody makes the call, rewardRootOf returns zero and nothing from that epoch is claimable by the nodes that earned it.

Nothing on this server does it for you, and that is also deliberate: this is a transaction, and automating it would mean a funded hot wallet sitting on the origin. The admin bell now tells you when one is waiting.

Or deploy the SettlementKeeper (below, after EpochManager) and fund it, so the call stops depending on anybody remembering. It pays whoever finalizes an epoch a flat bounty, first caller wins.

Fund it with ETH, not AXONCoins. The bounty reimburses gas, and gas is priced in ETH — so it is a flat amount rather than a share of the epoch, because finalizing a large epoch costs exactly the same gas as finalizing a small one. Rewards themselves are AXONCoins and are untouched by this: the keeper never moves them, it only closes the epoch that releases them. An epoch that pays nobody pays no bounty either — correct, since it does not need urgent settling, and today every epoch is empty, so a funded keeper would sit idle until the witness pool grows. finalize() stays permissionless either way; a keeper that became the only route could withhold settlements exactly as an operator could.

Genesis epoch

Witness selection is seeded from EpochManager.randomnessOf(epoch), which only exists once an epoch is on-chain — so the first epoch has nothing to draw from. Genesis fills that gap: one epoch with empty roots whose only payload is the seed. It can only be launched once; the button disables itself as soon as the chain reports epoch 0 submitted, because a second submission would revert (EpochExists) after spending gas.

Submit an epoch

Run pof-settle -epoch N and POST its JSON to /admin/contracts/settlement, then submit it here. Computing and posting are separate on purpose: you can read what a run produced — including who it refused to pay and why — before spending gas committing to it. Anyone can re-run the same command and must get the same roots; that is what the challenge window is for.

AXONCoins deliveries

Card payments that succeeded and are still owed AXONCoins. Sending is a a Treasury.release to each buyer (or AxonToken.transfer from your own wallet if no Treasury is deployed yet) — the treasury key is deliberately not on the web server, so a break-in there costs nobody their money. Each delivery is recorded as it lands, so stopping halfway loses nothing.
AXONCoins have to exist before they can be delivered. Until the supply is seeded the token's total supply is zero, every wallet on the network correctly reads 0, and a paid buyer sees nothing — the delivery has nowhere to come from. Seeding is mintGenesis, owner-only, and permanently disabled once closeGenesis() is called.

Mint or burn a specific amount (advanced)
A hand-typed supply figure is one missing or extra zero away from being wrong, and genesis minting cannot be undone by minting again — only by burning, which needs the treasury role. Both actions below spell out the amount and its value at the current sale rate before asking you to confirm.
Once the Treasury contract is wired, burning destroys AXONCoins the Treasury holds — burn takes no from address, so nobody can burn a holder's AXONCoins, including you. Before that, it burns from your own wallet and takes the treasury role first if needed. It will refuse to rotate that role away from a deployed Treasury, because doing so would silently stop epoch rewards being mintable.

Send AXONCoins by hand

For when an automatic path got it wrong — a delivery that credited the wrong amount, a refund, a goodwill payment. A reason is required, because an unexplained movement out of the treasury is indistinguishable from a theft, and the only person who can explain it is you, now.

Node registrations

Nodes register themselves at {{ url_for('main.pof_register') }}; each one proves ownership of its p2p key with an ed25519 signature before it is queued, so this is not an approval queue — it is a list of registrations waiting on gas. Submitting sends one registerWithSig per node from your wallet. Until a node is registered on-chain it has no payout address, and settlement rejects its receipts.
Register a node you run yourself. The queue above is for nodes owned by other people, who cannot spend your gas — they sign an intent and wait. A node you own needs none of that: NodeRegistry.register takes the wallet that sends the transaction as the owner, so connecting your wallet is the proof. The node prints its p2p public key on startup (proof-of-facilitation: p2p public key …).
