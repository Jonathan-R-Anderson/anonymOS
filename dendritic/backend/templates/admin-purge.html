Search & Purge Content

← Admin
Find specific media across the network and purge it: the object is deleted from the site's own store and from the DHT node gateway, every post/video that embeds it is removed, and its SHA-256 is blocklisted so it can never be re-uploaded. Search runs over the metadata the server still holds — hash, NSFW score, type, and post text — so nothing has to be pulled back from the DHT to locate it.
Shards already placed on other peers are not recalled — the peer protocol has no delete operation. Use DHT Purge when you need the per-layer report of exactly how far a purge got.
