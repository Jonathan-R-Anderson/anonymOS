MetaMask & Ethereum Mainnet

A wallet lets you sign in without a password, hold AXONCoins earned by running a node, and vote in the DAO. It is optional — password sign-in keeps working. New to any of this? Start with why crypto, and how it works.

1 — Install MetaMask
1
Get the browser extension.
Chrome, Firefox, Brave and Edge are all supported. Install only from the official site — wallet extensions are a common phishing target.
{% include "includes/metamask-icon.svg" %} Install MetaMask
2
Create a wallet and write down the recovery phrase.
Store those 12 words offline. Anyone who has them owns the wallet, and nobody — not MetaMask, not this site — can restore them for you.
2 — Connect to Ethereum Mainnet

AXONCoins settle on Ethereum Mainnet, an Ethereum layer-2. MetaMask ships with Ethereum mainnet only, so the network has to be added once.

Add it by hand instead
Network nameEthereum Mainnet
RPC URLhttps://eth.llamarpc.com
Chain ID1
Currency symbolETH
Block explorerhttps://etherscan.io
MetaMask → network dropdown → Add network → Add a network manually.
3 — Fund it (only if you plan to transact)

Signing in and voting cost nothing — a signature is not a transaction and never touches the chain. You only need ETH on Ethereum Mainnet to send transactions, and it must be ETH on Ethereum Mainnet, not on Ethereum mainnet: same address, different network.

Bridge ETH at etherscan.io
4 — Link it to your slip

Log in with your password, open profile settings, and press Link MetaMask. You will be asked to sign a short message proving you control the wallet — free, and it moves no funds. After that you can choose whether this slip accepts your password, the wallet, or either.
